# Capabilities

## Pipeline preparation

- Match known customers to historical relationship activity
- Apply minimum eligibility and risk controls
- Preserve relevant workflow state when rebuilding the pipeline
- Sort qualified records by priority and relationship evidence

## Operator review

- Search business, contact and industry context
- Filter by priority band and website state
- Inspect score rationale and recommended outreach angle
- Review recent relationship context before drafting

## AI-assisted drafting

- Construct a constrained context packet for the selected prospect
- Generate subject options and concise email copy
- Validate claims, tone and prohibited content
- Use a deterministic fallback when generation fails
- Allow human editing before draft creation

## Delivery controls

- Create one Gmail draft after review
- Prepare a bounded batch for an approved segment
- Track draft status and failures
- Prevent automatic sending
